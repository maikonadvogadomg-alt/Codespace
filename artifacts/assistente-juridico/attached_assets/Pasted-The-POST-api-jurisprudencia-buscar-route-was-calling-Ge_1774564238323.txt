/api/jurisprudencia/buscar was burning AI credits (Gemini) to hallucinate jurisprudence results. This replaces it with direct calls to the free DataJud CNJ public API, returning real process data at zero AI cost.

Key changes
Query strategy: Switched from Gemini prompt to Elasticsearch multi_match across assuntos.nome, movimentos.nome, classe.nome, orgaoJulgador.nome — matching how users search (by subject/term, not process number)
Parallel tribunal fetches: Promise.all over all selected tribunals (default: STJ + TRF1–TRF6); individual failures log and return [] without aborting the full request
Response mapping: DataJud _source → frontend results shape:
processo ← numeroProcesso
tribunal ← tribunal
tipo ← classe.nome
data ← dataAjuizamento (pt-BR formatted)
relator ← orgaoJulgador.nome
tese ← assuntos[].nome joined
ementa ← synthetic descriptor: "Classe: X | Assunto(s): Y | Último movimento: Z" (DataJud has no ementa field)
// Before: Gemini AI call (costs money, hallucinates)

// After: parallel DataJud fetches with real process data
const allHitsArrays = await Promise.all(selectedTribunais.map(fetchTribunal));
const allHits = allHitsArrays.flat();
Auth: reuses existing DATAJUD_API_KEY constant (process.env.DATAJUD_API_KEY with public key fallback), consistent with other DataJud routes in the file
.gitignore: added to exclude node_modules/ and build artifacts
