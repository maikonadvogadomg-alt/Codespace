## Como Funciona o JWT para PDJd

O código gera um **JSON Web Token (JWT)** que é enviado para o endpoint de autenticação do PDJd. O servidor responde com um **access_token** no formato Bearer.

## Fluxo Completo (VBA/Excel)

```vba
Sub GerarTokenPDJd()
    Dim http As Object
    Dim url As String, payload As String, token As String
    
    ' 1. GERAR JWT (você já tem essa parte)
    token = GerarJWT_PDjd("SEU_CLIENT_ID", "SEU_CLIENT_SECRET")
    
    ' 2. URL ENCODE do JWT
    url = "https://api.pdjdtj.mg.gov.br/v1/auth/token"
    payload = "grant_type=client_credentials&client_id=SEU_ID&client_secret=SEU_SECRET&scope=processos.read"
    
    ' 3. POST com JWT para obter BEARER TOKEN
    Set http = CreateObject("MSXML2.XMLHTTP")
    http.Open "POST", url, False
    http.setRequestHeader "Content-Type", "application/x-www-form-urlencoded"
    http.setRequestHeader "Authorization", "Bearer " & token  ' ← AQUI!
    http.Send payload
    
    ' 4. EXTRAIR BEARER TOKEN da resposta
    Dim response As String
    response = http.responseText
    ' Extrair: {"access_token":"eyJhbGciOiJSUzI1NiIs...","expires_in":3600}
    
    ' Salvar token para usar nos filtros
    Range("B1").Value = Mid(response, InStr(response, """access_token"":""") + 15, 200)
End Sub
```

## Transformar JWT → Bearer (Passo a Passo)

```
1. JWT gerado: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
   ↓
2. Header: Authorization: Bearer [JWT]
   ↓  
3. POST para: https://api.pdjdtj.mg.gov.br/v1/auth/token
   ↓
4. Resposta: {"access_token":"SEU_BEARER_TOKEN"}
   ↓
5. Usar: Authorization: Bearer SEU_BEARER_TOKEN
```

## curl Completo (Pronto para Copiar)

```bash
# Passo 1: Gerar JWT (seu código VBA faz isso)
JWT="eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9.seu.jwt.aqui"

# Passo 2: Obter Bearer Token
curl -X POST "https://api.pdjdtj.mg.gov.br/v1/auth/token" \
  -H "Authorization: Bearer $JWT" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grant_type=client_credentials"

# Passo 3: Usar Bearer Token nos filtros COJEF
BEARER_TOKEN="resposta.access_token"
curl -X GET "https://api.pdjdtj.mg.gov.br/v1/processos/busca?classeProcessual=Portaria+Cojef&dataInicio=2026-01-01" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
