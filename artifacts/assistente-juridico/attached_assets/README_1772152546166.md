# jwt-tools

Pequeno utilitário para gerar/verificar JWT RS256 a partir de uma chave privada RSA.

Passos rápidos:

1. Copie sua chave privada `chave_privada.pem` para a pasta `jwt-tools` OU passe o caminho completo como argumento.
2. Instale dependências:

```bash
cd jwt-tools
npm install
```

3. Gerar chave pública (opcional — o script criará `maikon.pub.pem` a partir da privada):

```bash
# usando arquivo na mesma pasta
npm run genpub

# ou com caminho absoluto
node genpub.js "C:/Users/Caldeira/chave_privada.pem"
```

4. Gerar um token JWT (assinatura RS256):

```bash
npm run sign
# ou passando o caminho da chave privada
node sign.js "C:/Users/Caldeira/chave_privada.pem"
```

5. Verificar um token:

```bash
# token como argumento; assume `maikon.pub.pem` na pasta
npm run verify -- maikon.pub.pem "SEU_TOKEN_AQUI"

# ou
node verify.js maikon.pub.pem "SEU_TOKEN_AQUI"
```

Notas:
- Proteja `chave_privada.pem` e não a compartilhe.
- Os scripts são simples de exemplo; adapte o payload conforme necessário.

Se você precisa usar direto no PJUD (pronto para enviar):

1. Gerar token curto (ex.: 5 minutos) com configurações específicas:

```powershell
# argumentos: --key (caminho da chave), --iss, --aud, --sub, --exp, --out
node gen_pjud.js --key "C:/Users/Caldeira/chave_privada.pem" --iss "https://seu-issuer.example" --aud "pjud" --sub "09494128648" --exp 300 --out pjud_token.txt
```

2. Usar o token em chamadas ao PJUD (header Authorization):

```powershell
curl -X GET "https://api-pjud.exemplo/endpoint" -H "Authorization: Bearer $(Get-Content pjud_token.txt -Raw)"
```

3. Fazer uma chamada de teste com o script incluido (`call_pjud.js`):

```powershell
node call_pjud.js --url "https://api-pjud.exemplo/endpoint" --tokenfile pjud_token.txt
```

4. Se o PJUD requer fluxo OAuth2 `client_assertion`, envie o JWT como `client_assertion`:

```bash
curl -X POST "https://authorization-server.example/token" \
	-d "grant_type=client_credentials&client_id=SEU_CLIENT_ID&client_assertion_type=urn:ietf:params:oauth:client-assertion-type:jwt-bearer&client_assertion=$(cat pjud_token.txt)" \
	-H "Content-Type: application/x-www-form-urlencoded"
```

Observações:
- `--exp` aceita segundos (ex: `300`) ou formatos como `5m`.
- Ajuste `iss`/`aud`/`sub` conforme o contrato do PJUD.
- Token com validade curta (ex.: 5 minutos) é recomendado.
