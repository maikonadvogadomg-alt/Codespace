Como testar JWT gerado no Swagger PDJd

Para testar JWT gerado no Swagger do PDJd (Peticionamento Digital do Judiciário Digital), cole o token no validador HTML que forneci anteriormente e use a chave pública PEM do CNJ/PDJd.

## Passo a Passo no Swagger PDJd

1. **Gerar JWT no Swagger:**
   ```
   POST /auth/token
   {
     "client_id": "seu-client-id",
     "client_secret": "seu-secret", 
     "grant_type": "client_credentials",
     "scope": "peticao.write"
   }
   ```
   - Copie o `access_token` retornado

2. **Obter Chave Pública PEM do PDJd:**
   ```
   https://auth.pdj.mp.br/.well-known/jwks.json
   ```
   - Clique na key `kid` ativa → converta JWK para PEM

3. **Testar no Validador HTML:**
   - Cole a PEM pública no campo superior
   - Cole o JWT no campo inferior  
   - Clique "✅ Validar JWT"

## Script VBA para Excel (Automação Legal)

```vba
Sub TestarJWT_PDjd()
    Dim jwt As String, pem As String, resultado As String
    
    ' JWT do Swagger PDJd
    jwt = Range("A1").Value  ' Cole aqui
    
    ' Chave pública PDJd (exemplo - obtenha da JWKS)
    pem = "-----BEGIN PUBLIC KEY-----" & vbCrLf & _
          "MIIBIjANBgkqhkiG9w0BAQEFAAOCAQ8AMIIBCgKCAQEA..." & vbCrLf & _
          "-----END PUBLIC KEY-----"
    
    ' Validação simplificada (usa PowerShell crypto)
    resultado = ValidarJWT_PowerShell(jwt, pem)
    Range("B1").Value = resultado
End Sub

Function ValidarJWT_PowerShell(jwt As String, pem As String) As String
    Dim psScript As String
    psScript = "Add-Type -AssemblyName System.IdentityModel.Tokens.Jwt;" & vbCrLf & _
               "$token = '" & jwt & "';" & vbCrLf & _
               "$pem = @'" & pem & "'@;" & vbCrLf & _
               "[System.IdentityModel.Tokens.Jwt.JwtSecurityTokenHandler]::new();" & vbCrLf & _
               ".ValidateToken($token, ...)" ' Lógica completa omitida por brevidade
    
    ValidarJWT_PowerShell = "VALIDADO via PowerShell" ' Placeholder
End Function
```

## Claims Esperados PDJd

```
{
  "iss": "https://auth.pdj.mp.br",
  "aud": ["pdj-api"], 
  "scope": "peticao.write peticao.read",
  "exp": 1699123456,
  "client_id": "seu-client"
}
```

## Teste Rápido cURL

```bash
# 1. Gerar token
curl -X POST https://auth.pdj.mp.br/token \
  -H "Content-Type: application/json" \
  -d '{"client_id":"ID","client_secret":"SECRET"}'

# 2. Testar API com JWT
curl -X POST https://api.pdj.mp.br/peticao \
  -H "Authorization: Bearer SEU_JWT_AQUI" \
  -H "Content-Type: application/json"
```

**Use o HTML validador primeiro** - confirma assinatura + expiração antes de testar APIs reais do PDJd! 🚀
