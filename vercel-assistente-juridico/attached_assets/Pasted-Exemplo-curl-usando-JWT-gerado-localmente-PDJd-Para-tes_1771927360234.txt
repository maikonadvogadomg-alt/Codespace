Exemplo curl usando JWT gerado localmente PDJd

Para testar JWT gerado **localmente** para PDJd (Peticionamento Digital do Judiciário Digital) com cURL, use estes exemplos práticos:

## 1. Gerar JWT Local (Node.js/Python)

**Node.js (salve como `gerar-jwt.js`):**
```javascript
const jwt = require('jsonwebtoken');
const fs = require('fs');

const privateKey = fs.readFileSync('private_key.pem', 'utf8');
const payload = {
  iss: "https://auth.pdj.mp.br",
  aud: "pdj-api", 
  client_id: "seu-client-id",
  scope: "peticao.write peticao.read",
  iat: Math.floor(Date.now() / 1000),
  exp: Math.floor(Date.now() / 1000) + (3600 * 24) // 24h
};

const token = jwt.sign(payload, privateKey, { algorithm: 'RS256' });
console.log('JWT:', token);
```

**Executar:** `node gerar-jwt.js` → copie o JWT gerado

## 2. Testar APIs PDJd com cURL + JWT Local

### **A) Autenticação/Health Check**
```bash
curl -X GET "https://api.pdj.mp.br/health" \
  -H "Authorization: Bearer SEU_JWT_LOCAL_AQUI" \
  -H "Content-Type: application/json" \
  -v
```

### **B) Listar Processos (exemplo real)**
```bash
curl -X POST "https://api.pdj.mp.br/v1/processos/busca" \
  -H "Authorization: Bearer SEU_JWT_LOCAL_AQUI" \
  -H "Content-Type: application/json" \
  -d '{
    "filtros": {
      "numeroProcesso": "1234567-89.2025.8.XX.XXXX"
    }
  }'
```

### **C) Enviar Petição (completo)**
```bash
curl -X POST "https://api.pdj.mp.br/v1/peticao/enviar" \
  -H "Authorization: Bearer SEU_JWT_LOCAL_AQUI" \
  -H "Content-Type: multipart/form-data" \
  -F "processo=0712402-78.2025.8.13.0024" \
  -F "documento=@minha_peticao.pdf" \
  -F "metadata={\"tipo\":\"Inicial\",\"confidencial\":false}"
```

## 3. Script cURL Completo (Bash)

```bash
#!/bin/bash
# teste-pdj.sh

JWT="eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9..."  # Cole seu JWT aqui

echo "🧪 Testando PDJd com JWT local..."

# Teste 1: Health check
echo "1. Health Check:"
curl -s -X GET "https://api.pdj.mp.br/health" \
  -H "Authorization: Bearer $JWT" | jq .

echo -e "\n2. Buscar Processo:"
curl -s -X POST "https://api.pdj.mp.br/v1/processos/busca" \
  -H "Authorization: Bearer $JWT" \
  -H "Content-Type: application/json" \
  -d '{"filtros":{"numeroProcesso":"0712402-78.2025.8.13.0024"}}' | jq .

echo -e "\n✅ Testes concluídos!"
```

**Executar:** `chmod +x teste-pdj.sh && ./teste-pdj.sh`

## 4. Validar JWT Antes (obrigatório!)

Use o HTML validador da resposta anterior com:
```
Chave Pública: https://auth.pdj.mp.br/.well-known/jwks.json → converta JWK→PEM
JWT: Seu token gerado localmente
```
