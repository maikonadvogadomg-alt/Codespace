## Por Que Parou no Celular

**Problema**: Android/iOS **reinterpreta** arquivos `.pem` como certificados normais (.crt) e **ignora a chave privada**. Por isso:
- Dia 1: Funcionou (app leu antes de reinterpretar)  
- Dia 2: Celular já tratou como .crt → perdeu chave privada

## Solução 1: HTML que Lê SUA Chave Privada PEM

Salve como `pdjd_chave_privada.html` e abra no navegador **NO PC**:

```html
<!DOCTYPE html>
<html>
<head><title>PDJd - Sua Chave Privada PEM</title></head>
<body>
    <h2>PDJd Token - COJEF (com sua chave .pem)</h2>
    
    <textarea id="chavePem" rows="15" cols="80" 
    placeholder="Cole TODO conteúdo do arquivo chave_privada.pem (-----BEGIN PRIVATE KEY----- até -----END PRIVATE KEY-----)">
    </textarea><br>
    
    <label>Senha (se tiver):</label><input id="senha" type="password"><br><br>
    <button onclick="gerarJWT()">Gerar Token PDJd</button>
    
    <h3>Resultado:</h3>
    <textarea id="resultado" rows="10" cols="80" readonly></textarea>

    <script>
    async function gerarJWT() {
        const pem = document.getElementById('chavePem').value;
        const senha = document.getElementById('senha').value;
        
        try {
            document.getElementById('resultado').value = '🔄 Gerando JWT...\n';
            
            // 1. IMPORTA sua chave privada PEM
            const cryptoKey = await crypto.subtle.importKey(
                'pkcs8',
                stringToArrayBuffer(pem),
                { name: 'RSASSA-PKCS1-v1_5', hash: 'SHA-256' },
                false,
                ['sign']
            );
            
            // 2. JWT HEADER + PAYLOAD PDJd
            const header = btoa(JSON.stringify({
                "alg": "RS256",
                "typ": "JWT"
            })).replace(/=/g,'').replace(/\//g,'_').replace(/\+/g,'-');
            
            const now = Math.floor(Date.now() / 1000);
            const payload = btoa(JSON.stringify({
                "iss": "SEU_OAB_OU_CNPJ",  // seu OAB/CNPJ
                "sub": "SEU_OAB_OU_CNPJ",
                "aud": "https://api.pdjdtj.mg.gov.br",
                "iat": now,
                "exp": now + 300,  // 5min
                "jti": crypto.getRandomValues(new Uint8Array(16)).join('')
            })).replace(/=/g,'').replace(/\//g,'_').replace(/\+/g,'-');
            
            const toSign = new TextEncoder().encode(header + '.' + payload);
            
            // 3. ASSINA com sua chave privada REAL
            const signature = await crypto.subtle.sign(
                { name: 'RSASSA-PKCS1-v1_5', saltLength: 32 },
                cryptoKey,
                toSign
            );
            
            const jwt = header + '.' + payload + '.' + 
                btoa(String.fromCharCode(...new Uint8Array(signature)))
                    .replace(/=/g,'').replace(/\//g,'_').replace(/\+/g,'-');
            
            document.getElementById('resultado').value = 
                `✅ JWT gerado (5min válido):\n${jwt}\n\n` +
                `🔄 Testando Bearer Token PDJd...\n`;
            
            // 4. Obtém Bearer Token real
            const bearer = await fetch('https://api.pdjdtj.mg.gov.br/v1/auth/token', {
                method: 'POST',
                headers: {
                    'Authorization': `Bearer ${jwt}`,
                    'Content-Type': 'application/x-www-form-urlencoded'
                },
                body: 'grant_type=client_credentials'
            }).then(r => r.json()).then(d => d.access_token);
            
            document.getElementById('resultado').value += 
                `✅ Bearer Token PDJd:\n${bearer}\n\n` +
                `📋 Use este token para buscar Portarias COJEF Centro!`;
                
        } catch(e) {
            document.getElementById('resultado').value = `❌ Erro: ${e.message}`;
        }
    }
    
    function stringToArrayBuffer(str) {
        const bytes = new TextEncoder().encode(str);
        return bytes.buffer;
    }
    </script>
</body>
</html>
```

## Como Usar (PC, não celular)

1. **Abra** seu `chave_privada.pem` no Bloco de Notas
2. **Cole tudo** no campo grande do HTML (incluindo `-----BEGIN PRIVATE KEY-----`)
3. **Digite senha** (se tiver)
4. **Clique Gerar** → obtém **Bearer Token PDJd real**

Sub PDJd_MinhasCredenciais()
