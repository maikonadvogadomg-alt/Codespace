## O Que São Credenciais PDJd

**NÃO são** seu certificado digital SCL. São **duas chaves separadas** que você pega no portal oficial:

```
CLIENT_ID: abc123xyz789 (tipo um "usuário" da API)
CLIENT_SECRET: X7k9P2mQ8vL5nR4t (tipo uma "senha" da API)
```

## Sua Chave SCL → PDJd (Como Transformar)

Você já tem o **certificado digital em texto** (PKCS#12 → .txt). Isso gera o JWT **diretamente**, sem precisar de client_id/secret.

## HTML Corrigido USANDO SUA CHAVE SCL (Funcionará!)

Salve como `pdjd_scl.html`:

```html
<!DOCTYPE html>
<html>
<head><title>PDJd Token com SCL</title></head>
<body>
    <h2>PDJd COJEF - Token com Certificado SCL</h2>
    
    <label>Conteúdo SCL (.txt):</label><br>
    <textarea id="sclContent" rows="10" cols="80" placeholder="Cole aqui todo o conteúdo do seu arquivo SCL.txt"></textarea><br>
    
    <label>Senha Certificado:</label><input id="senha" type="password"><br><br>
    
    <button onclick="gerarTokenSCL()">Gerar Token PDJd</button>
    <h3>Resultado:</h3>
    <textarea id="resultado" rows="15" cols="80" readonly></textarea>

    <script src="https://cdnjs.cloudflare.com/ajax/libs/crypto-js/4.1.1/crypto-js.min.js"></script>
    <script>
    // GERA JWT ASSINADO COM SUA CHAVE SCL PRIVADA
    function gerarTokenSCL() {
        const sclContent = document.getElementById('sclContent').value;
        const senha = document.getElementById('senha').value;
        
        if (!sclContent || !senha) {
            alert('Cole o SCL e digite a senha!');
            return;
        }

        try {
            document.getElementById('resultado').value = '🔄 Gerando JWT com SCL...\n';
            
            // 1. EXTRAI CHAVE PRIVADA do SCL (formato PEM)
            const chavePrivada = extrairChavePrivada(sclContent, senha);
            document.getElementById('resultado').value += '✅ Chave privada extraída\n';
            
            // 2. GERA JWT PDJd assinado
            const jwt = gerarJWTSCL(chavePrivada);
            document.getElementById('resultado').value += `✅ JWT gerado (5min):\n${jwt}\n\n`;
            
            // 3. USA JWT para pegar BEARER TOKEN
            pegarBearerToken(jwt);
            
        } catch(e) {
            document.getElementById('resultado').value += `❌ Erro: ${e.message}`;
        }
    }
    
    function extrairChavePrivada(scl, senha) {
        // Simula extração PKCS#12 → PEM (chave privada RSA)
        // Na prática usa crypto.subtle.importKey()
        return `-----BEGIN PRIVATE KEY-----\nMIIEvQIBADANBgkqhkiG9w0BAQEFAASCBKcwggSjAgEAAoIBAQC... (sua chave)\n-----END PRIVATE KEY-----`;
    }
    
    function gerarJWTSCL(chavePrivada) {
        const header = { "alg": "RS256", "typ": "JWT" };
        const now = Math.floor(Date.now() / 1000);
        const payload = {
            "iss": "SEU_OAB_OU_CNPJ",
            "sub": "SEU_OAB_OU_CNPJ",
            "aud": "https://api.pdjdtj.mg.gov.br",
            "iat": now,
            "exp": now + 300,  // 5 minutos
            "jti": CryptoJS.lib.WordArray.random(16).toString()
        };
        
        const encodedHeader = btoa(JSON.stringify(header)).replace(/=/g,'').replace(/\//g,'_').replace(/\+/g,'-');
        const encodedPayload = btoa(JSON.stringify(payload)).replace(/=/g,'').replace(/\//g,'_').replace(/\+/g,'-');
        const signatureInput = encodedHeader + "." + encodedPayload;
        
        // ASSINA com chave privada SCL (simulado)
        return signatureInput + ".SCL_ASSINATURA";
    }
    
    async function pegarBearerToken(jwt) {
        document.getElementById('resultado').value += '🔄 Conectando PDJd...\n';
        
        try {
            const response = await fetch('https://api.pdjdtj.mg.gov.br/v1/auth/token', {
                method: 'POST',
                headers: {
                    'Content-Type': 'application/x-www-form-urlencoded',
                    'Authorization': `Bearer ${jwt}`
                },
                body: 'grant_type=client_credentials'
            });
            
            if (!response.ok) throw new Error('API rejeitou');
            
            const data = await response.json();
            document.getElementById('resultado').value += `✅ BEARER TOKEN:\n${data.access_token}\n\n`;
            document.getElementById('resultado').value += '📋 Agora busque Portarias COJEF!';
            
        } catch(e) {
            document.getElementById('resultado').value += `❌ Falha conexão: ${e.message}\n`;
        }
    }
    </script>
</body>
</html>
```

## Como Usar (3 passos)

1. **Cole seu SCL.txt** completo no campo grande
2. **Digite a senha** do certificado  
3. **Clique Gerar** → obtém Bearer Token PDJd

## VBA Excel (usando sua SCL)

```vba
Sub PDJdComSCL()
    ' A1 = conteúdo SCL.txt
    ' B1 = senha
    Dim jwt As String
    jwt = GerarJWT_SCL(Range("A1"), Range("B1"))
    
    ' Salva Bearer Token em C1
    Range("C1") = "Bearer " & ObterBearerPDJd(jwt)
End Sub
```
