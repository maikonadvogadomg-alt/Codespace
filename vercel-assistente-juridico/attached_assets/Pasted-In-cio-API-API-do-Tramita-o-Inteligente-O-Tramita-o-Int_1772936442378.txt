Início API
API do Tramitação Inteligente
O Tramitação Inteligente disponibiliza uma API para integração com sistemas externos.

Como toda API, é destinada a desenvolvedores. Se você não é desenvolvedor (ou não tem um desenvolvedor), e deseja integrar o Tramitação Inteligente com algum outro sistema, preencha o formulário abaixo solicitando que nosso time desenvolva a integração desejada por você.

Já se você é desenvolvedor (ou tem um desenvolvedor no seu time), a API é simples de usar e adere aos padrões RESTful. As chaves de API são fáceis de gerar e são do tipo Bearer token. Todos os requests e respostas são em formato JSON. A documentação é servida no formato Swagger/OpenAPI, e é interativa, sendo possível testar as requisições diretamente a partir dela.

Além disto, o Tramitação Inteligente possui um sistema de webhooks para notificações de eventos em tempo real, sendo possível construir integrações de mão dupla.

Novas capacidades são adicionadas com base nos requerimentos dos nossos assinantes utilizando o formulário abaixo.
