Como gerar JWT com chave PEM localmente

Para gerar JWT com chave PEM localmente, use JavaScript no navegador com a Web Crypto API. É simples e funciona offline.

## HTML Completo (Salve como `jwt-pem.html`)

```html
<!DOCTYPE html>
<html>
<head>
    <title>Gerar JWT com Chave PEM</title>
    <meta charset="UTF-8">
</head>
<body>
    <h2>🔐 Gerador JWT - Chave Privada PEM</h2>
    
    <label>Chave Privada PEM (cole tudo):</label><br>
    <textarea id="chavePem" rows="12" cols="80" 
    placeholder="-----BEGIN PRIVATE KEY-----
MIIEvgIBADANBgkqhkiG9w0BAQEFAASCBKgwggSkAgEAAoIBAQC7... 
-----END PRIVATE KEY-----"></textarea><br><br>
    
    <label>Payload JSON:</label><br>
    <textarea id="payload" rows="4" cols="80">{
  "sub": "12345678",
  "iat": 1640995200,
  "iss": "cojef",
  "aud": "pdjd"
}</textarea><br><br>
    
    <button onclick="gerarJWT()">Gerar JWT</button>
    <button onclick="limpar()">Limpar</button>
    
    <h3>Resultado:</h3>
    <textarea id="resultado" rows="6" cols="80" readonly style="background: #f0f0f0;"></textarea>

    <script>
    async function gerarJWT() {
        const pem = document.getElementById('chavePem').value.trim();
        const payload = JSON.parse(document.getElementById('payload').value);
        const resultado = document.getElementById('resultado');
        
        try {
            resultado.value = '🔄 Gerando...\n';
            
            // 1. Converte PEM para ArrayBuffer
            const cryptoKey = await crypto.subtle.importKey(
                'pkcs8', 
                stringToArrayBuffer(pem),
                { name: 'RSASSA-PKCS1-v1_5', hash: 'SHA-256' },
                false,
                ['sign']
            );
            
            // 2. Header JWT
            const header = { alg: 'RS256', typ: 'JWT' };
            
            // 3. Codifica Base64Url
            const encodedHeader = b64UrlEncode(JSON.stringify(header));
            const encodedPayload = b64UrlEncode(JSON.stringify(payload));
            const toSign = `${encodedHeader}.${encodedPayload}`;
            
            // 4. Assina
            resultado.value = '✍️ Assinando...\n';
            const signature = await crypto.subtle.sign(
                'RSASSA-PKCS1-v1_5',
                cryptoKey,
                new TextEncoder().encode(toSign)
            );
            
            // 5. Monta JWT final
            const jwt = `${toSign}.${b64UrlEncode(signature)}`;
            resultado.value = `✅ JWT gerado!\n\n${jwt}`;
            
            // Testa cópia
            navigator.clipboard.writeText(jwt).then(() => {
                resultado.value += '\n\n📋 JWT copiado para área de transferência!';
            });
            
        } catch (error) {
            resultado.value = `❌ Erro: ${error.message}\n\nDicas:\n- Verifique se a chave PEM tem -----BEGIN/END PRIVATE KEY-----\n- Payload deve ser JSON válido`;
        }
    }
    
    // Base64 URL seguro
    function b64UrlEncode(buffer) {
        let str = btoa(String.fromCharCode(...new Uint8Array(buffer)))
            .replace(/\+/g, '-')
            .replace(/\//g, '_')
            .replace(/=/g, '');
        return str;
    }
    
    function stringToArrayBuffer(str) {
        const bytes = new TextEncoder().encode(str);
        return bytes.buffer;
    }
    
    function limpar() {
        document.getElementById('resultado').value = '';
        document.getElementById('chavePem').focus();
    }
    </script>
</body>
</html>
```

## Como Usar

1. **Salve** o código acima como `jwt-pem.html`
2. **Abra** no navegador (Chrome/Firefox)
3. **Cole** sua chave privada PEM completa (com `-----BEGIN PRIVATE KEY-----` e `-----END PRIVATE KEY-----`)
4. **Ajuste** o payload JSON conforme o PDJd/COJEF
5. **Clique** "Gerar JWT"

## Payload Exemplo PDJd/COJEF

```json
{
  "sub": "SEU_CPF",
  "iat": 1640995200,
  "iss": "cojef",
  "aud": "pdjd"
}
```

## Por Que Funciona

- ✅ **100% local** - sem servidor
- ✅ **Web Crypto API** - nativa do navegador
- ✅ **PKCS#8 PEM** - formato que você já tem
- ✅ **RS256** - padrão dos sistemas judiciais brasileiros
- ✅ **Base64Url** - formato JWT correto

**Teste agora** com sua chave PEM! O JWT sairá pronto para usar no PDJd. [4]
